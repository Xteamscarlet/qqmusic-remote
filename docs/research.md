# 扩展设备调研结论

> 结论时间：2026-08。当时决定：小米电视**暂缓**、小度音箱**不做**。本文记录调研依据，供后续重启时参考。

## 小米电视

### 方案 A：ADB 通用遥控（可行，但前提不满足）

- 小米电视开启「设置 → 关于 → 连点版本号 → 开发者选项 → ADB 调试」后，电脑可 `adb connect <电视IP>:5555`；
- 之后用 `adb shell input keyevent` 模拟遥控器（方向/确认/返回/播放暂停/音量），`am start` 启动 App，可实现通用遥控，动作稳定；
- 在电视 App 内部搜歌点播依赖界面布局（uiautomator dump 或坐标），较脆弱；
- **放弃原因：本机用户的电视无法开启 ADB（定制版/受限）。**

### 方案 B：DLNA 投屏（可行，范围有限）

- 小米电视原生支持 DLNA DMR；电脑端通过 SSDP 发现设备 → 解析 AVTransport 的 controlURL → SOAP 调 `SetAVTransportURI` 推送音频 URL → `Play`；
- 支持播放/暂停/停止/跳转/音量；可用 `pysimpledlna`、`async_upnp_client` 或手写 SOAP；
- **关键限制：只能推本地音频文件或可直链的网络音频。QQ 音乐在线歌曲拿不到直链（加密/会员），无法把 QQ 音乐的歌直接投到电视。**

## 小度音箱（结论：不做）

- 底层通信协议为百度私有，未公开；局域网 SSDP 只能拿到设备描述，实际控制指令需云端认证；
- DuerOS 开放平台面向硬件厂商/企业开发者（需认证、SDK 日调用量超 1000 次须设备认证），**没有面向个人用户的「远程控制已购音箱」API**；
- 逆向/抓包有封号与违反用户协议风险，成功率低。

## 若未来重启电视控制

1. 确认电视能否开 ADB → 能则走方案 A（通用遥控层即可覆盖日常听歌）；
2. 不能则做方案 B 的 DLNA 投屏模块（局域网扫描 + 本地 HTTP 服务托管音频 + SetAVTransportURI），并把"只能投本地/直链音频"写进交互提示。
